# 如何使用 Cursor，以及如何把上下文放进仓库

这个仓库记录两件事：Cursor 里仓库、会话、上下文实际存在哪里；长期项目怎样把细节留在 Git 里，而不是只靠一条聊天的压缩摘要。

整理日期：2026-11-19。依据是当时的 Cursor 官方文档。界面、保留期限和检索行为会变，以文档为准。各篇末尾有用到的链接。

## 阅读顺序

1. [仓库与会话](docs/01-repo-and-session.md)：repo 是什么，一条会话和它是什么关系。
2. [上下文存在哪里](docs/02-context-storage.md)：一年期项目里，对话记录、检查点、规则和云端状态各自落在哪；模型窗口为什么装不下一整年。
3. [按话题写笔记](docs/03-topic-notes.md)：话题结束时把「问题 → 结论」写入 Git 之后，以后的会话怎样才能搜到、读到，以及笔记里该留什么。

## 使用方式

这些文件是给人评审、也给以后的 Agent 阅读的项目知识。它们随这个仓库走。新对话不会自动把全文装进提示；怎样让 Agent 在需要时读到它们，见第三篇。
